## Featured Project: Pip — AI Project Manager

**Built on Claude Code · Deployed to a 7-person cross-functional team**

Architecture: Custom `/pm-*` slash-command layer connecting three external APIs (Toggl, Monday.com, Fireflies). Team-wide installation via shared Google Drive sync + shell setup script. Each command abstracts multi-step API calls into a single interaction.

Commands shipped:
- `/pm-status` — retainer hour pacing vs. budget with on/over/under alert logic
- `/pm-sprint` — current sprint tasks + hours context in single view
- `/pm-plan` — sprint planning mode: budget, sprint, backlog, recommendations
- `/pm-meeting` — Fireflies transcript → Monday tasks: fuzzy-matches action items to existing tasks, creates new ones, assigns owners, posts context updates
- `/pm-geekbot` — standups generated from Toggl history + Monday due-today tasks
- `/pm-report` — client update email drafted from Monday task status + Toggl hours
- `/pm-mywork` — cross-board task view filtered by team member or function

**Result: 20 min → 20 sec, every meeting, every client.**
